# Página de Novas Contratações

Este é um projeto desenvolvido como parte do desafio **7DaysOfCode**, focado em reforçar os conhecimentos adquiridos ao longo dos cursos de **HTML** e **CSS**. A tarefa consistiu em transformar um layout criado no Figma em uma página real de um site para uma empresa de TI, com foco em novas contratações.

## Objetivo

O objetivo deste projeto foi criar uma página atraente e funcional para uma empresa de TI, visando divulgar as oportunidades de emprego e atrair candidatos. O layout foi fornecido no Figma, e o desafio consistiu em implementá-lo utilizando HTML e CSS.

## Funcionalidades

- **Layout Responsivo**: A página se adapta a diferentes tamanhos de tela, tornando-se acessível em dispositivos móveis e desktops.
- **Estilo Moderno**: Cores e fontes modernas foram escolhidas para criar uma interface amigável e profissional.
- **Estrutura de Navegação**: A página inclui uma barra de navegação, seções de informações e um formulário de inscrição.

## Tecnologias Utilizadas

- **HTML**: Estruturação da página e conteúdo.
- **CSS**: Estilização da página e design responsivo.
- **Figma**: Utilizado para criar o layout do projeto.
